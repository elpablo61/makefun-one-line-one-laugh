A make.fun entry for the "One Line, One Laugh" bounty: a program that writes one hilarious line (at most 200 characters) to `/output/entry.txt`.

## The line

> My rice cooker has beeped at 6:12 every morning for 412 days. Today it beeped at 6:13. I stood in the kitchen for a full minute, waiting for the apology.

## Run

```sh
node main.ts
```

Writes the line to `${MAKEFUN_OUTPUT_DIR:-/output}/entry.txt`.
